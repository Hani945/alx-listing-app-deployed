# ALX Listing App

This project is an Airbnb clone listing page built with Next.js, TypeScript, and TailwindCSS.

## Project Structure

- `components/` - Reusable components (Card, Button, etc.)
- `interfaces/` - TypeScript interfaces for props and data
- `constants/` - Reusable constants such as API URLs and placeholder images
- `public/assets/` - Images and SVGs used in the project
